# ETH Balance

Ethereum "Hello World": Get the ETH balance of any Ethereum address in ~25 lines of HTML + JS.

**Try it out: [shawntabrizi.com/ethbalance](https://shawntabrizi.com/ethbalance/)**

## How It Works

Enter an Ethereum address and click "Get Balance". Uses [ethers.js](https://docs.ethers.org/) to query a free public RPC endpoint — no API key or wallet needed.
